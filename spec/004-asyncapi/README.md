# Spec 004: AsyncAPI

**Created:** 2026-05-17
**Status:** Requirements Phase

## Topic Overview

Documentation for Brighter's AsyncAPI support, covering how Brighter can generate and consume AsyncAPI specifications. AsyncAPI is an open standard for defining asynchronous APIs, similar to what OpenAPI does for REST APIs. This documentation will explain how users can leverage AsyncAPI with Brighter to document their message-driven architectures, define channel bindings, and improve interoperability between services.
