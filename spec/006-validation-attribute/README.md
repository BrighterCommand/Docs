## Topic Overview

Document the validation attribute feature in Brighter, which allows requests
to be validated as part of the handler pipeline. This documentation is needed
to help users understand how to apply validation to their commands and events,
how the attribute fits into the middleware pipeline, and what behaviour to
expect when validation fails.
